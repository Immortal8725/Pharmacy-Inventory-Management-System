# HealthFirst PIMS

Desktop Pharmacy Inventory Management System for HealthFirst Pharmacy (PRO732).

Java Swing GUI, JDBC, role-based Admin/Cashier access, point of sale, billing, and reports.

**Run:** `java -jar dist/healthfirst_pims.jar`  
**Logins:** `admin` / `admin123` (Administrator), `cashier` / `cash123` (Cashier)

See `README.txt` for the full user manual, MySQL setup, and module guide.
